
# 💼 Interactive 3D Portfolio

This is a responsive and interactive 3D portfolio website created using **HTML**, **CSS**, and **JavaScript**. It includes a canvas-based animated background and showcases the developer's personal profile, skills, and project information in a clean and modern layout.

## 🚀 Live Preview

You can open the `index.html` file in any modern web browser to preview the portfolio locally.

---

## 📂 Project Structure

```

interactive-3d-portfolio/
│
├── index.html        # Main HTML file
├── styles.css        # Styling for layout and animations
├── script.js         # JavaScript for interactivity (e.g. animated bubbles)
└── profile.jpg       # Profile picture (replace with your own)

```

---

## ✨ Features

- Animated background using `<canvas>`
- Responsive layout for all screen sizes
- Profile photo and personal tagline
- Smooth scroll navigation links
- Sections:
  - About Me
  - Skills
  - Projects
  - Contact Information

---

## 📌 How to Use

1. Clone or download this repository.
2. Replace `profile.jpg` with your own image.
3. Update content inside `index.html` to match your personal details.
4. Optionally update the `script.js` to customize the background animation.
5. Open `index.html` in a browser to view the portfolio.
